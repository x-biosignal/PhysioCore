# Subject-level metadata table of a PhysioCohort

Subject-level metadata table of a PhysioCohort

## Usage

``` r
cohortData(x)

# S4 method for class 'PhysioCohort'
cohortData(x)

cohortData(x) <- value

# S4 method for class 'PhysioCohort'
cohortData(x) <- value
```

## Arguments

- x:

  A `PhysioCohort`.

- value:

  A subject-level `DataFrame` (setter); one row per subject.

## Value

`cohortData()` the subject-level `DataFrame`.
