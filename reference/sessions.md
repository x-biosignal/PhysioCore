# Access the sessions of a PhysioLongitudinal

Access the sessions of a PhysioLongitudinal

## Usage

``` r
sessions(x)

# S4 method for class 'PhysioLongitudinal'
sessions(x)

sessions(x) <- value

# S4 method for class 'PhysioLongitudinal'
sessions(x) <- value
```

## Arguments

- x:

  A `PhysioLongitudinal`.

- value:

  A named list / SimpleList of sessions (setter).

## Value

`sessions()` a `SimpleList`; setter returns the object.
