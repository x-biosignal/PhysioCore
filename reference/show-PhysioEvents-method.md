# Show method for PhysioEvents

Show method for PhysioEvents

## Usage

``` r
# S4 method for class 'PhysioEvents'
show(object)
```

## Arguments

- object:

  A PhysioEvents object.

## Value

Returns `NULL` invisibly; called for the side effect of printing a
compact summary of the events to the console.
