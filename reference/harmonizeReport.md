# Report the channels dropped / renamed per session by harmonization

Report the channels dropped / renamed per session by harmonization

## Usage

``` r
harmonizeReport(long)
```

## Arguments

- long:

  A harmonized `PhysioLongitudinal`.

## Value

A named list (one entry per session) with `kept`, `dropped` and
`renamed` channels.
