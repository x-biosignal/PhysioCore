# Retrieve a single subject's longitudinal record by id

Retrieve a single subject's longitudinal record by id

## Usage

``` r
subject(x, id)
```

## Arguments

- x:

  A `PhysioCohort`.

- id:

  A subject id (name).

## Value

The subject's `PhysioLongitudinal`.
